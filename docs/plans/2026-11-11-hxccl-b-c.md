# hxccl B + C Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** hxccl의 모든 집합 연산과 Send/Recv·Group이 GPU 버퍼(CUDA IPC, GPU 리덕션)로 동작하고, `torch.distributed`의 `"hxccl"` 백엔드로 쓸 수 있게 한다.

**Architecture:** 알고리즘 안의 메모리 작업을 `MemOps` 인터페이스로 뽑아 CPU(`HostOps`)와 GPU(`DeviceOps`)가 같은 알고리즘 코드를 쓰게 한다. GPU 경로의 전송은 `IpcTransport`(상대 rank의 GPU 중간 버퍼에 `cudaMemcpyAsync` + MPI ready/done 신호)가, 리덕션은 CPU와 같은 원소 함수를 쓰는 CUDA 커널이 맡는다. PyTorch 백엔드는 C API 위의 C++ 확장이며 `mpirun`으로 띄운다.

**Tech Stack:** C++17, CUDA 12.2(sm_86), OpenMPI(apt), CMake ≥ 3.20, PyTorch 2.9.1+cu128 C++ extension, pytest, Nsight Systems/Compute, NVTX.

**Spec:** `docs/specs/2026-11-11-hxccl-b-gpu-c-torch-design.md`

## Review Focus

1. **rooted 집합 연산에서 NULL 버퍼**(non-root의 Reduce recv, Scatter send, Gather recv)와 device 포인터: NULL은 판정에서 빼고 GPU 경로를 타야 한다 → Task 5 `rooted_null_nonroot`.
2. **한 Group 안에서 같은 상대에게 Send 두 번 + 반대 방향 Recv**: 중간 버퍼를 순서대로 재사용해야 하고 교착 없이 끝나야 한다 → Task 5 `group_two_sends_same_peer`.
3. **중간 버퍼보다 큰 메시지와 나머지 덩어리**: `HXCCL_IPC_CHUNK=4096`에서 4097 B, 크기 0 → Task 4 테스트를 chunk 4096으로도 등록.
4. **in-place**(AllReduce `send==recv`, AllGather `send==recv+rank*count`, ReduceScatter, Gather/Scatter in-place)를 device 버퍼로 → Task 4·5의 in-place 케이스.
5. **같은 통신기에서 host 호출 뒤 device 호출, 다시 host 호출**: GPU 경로가 처음 쓰일 때의 지연 초기화가 모든 rank에서 같은 지점에 일어나야 하고, 이후 host 호출이 그대로 동작해야 한다 → Task 4 `host_device_host`.

```cpp
// rank 0 allocates a device buffer, fills it with 42, shares the IPC handle over MPI;
// rank 1 opens it, copies it into its own buffer and checks the values.
#include <cuda_runtime.h>
#include <mpi.h>
#include <cstdio>
#include <vector>
#define CK(x) do { cudaError_t e = (x); if (e != cudaSuccess) { \
  std::printf("rank %d: %s failed: %s\n", rank, #x, cudaGetErrorString(e)); MPI_Abort(MPI_COMM_WORLD, 1); } } while (0)
int main(int argc, char** argv) {
  MPI_Init(&argc, &argv);
  int rank; MPI_Comm_rank(MPI_COMM_WORLD, &rank);
  CK(cudaSetDevice(0));
  const size_t n = 1 << 20;
  float* buf; CK(cudaMalloc(&buf, n * sizeof(float)));
  cudaIpcMemHandle_t h{};
  if (rank == 0) {
    std::vector<float> host(n, 42.0f);
    CK(cudaMemcpy(buf, host.data(), n * sizeof(float), cudaMemcpyHostToDevice));
    CK(cudaIpcGetMemHandle(&h, buf));
  }
  MPI_Bcast(&h, sizeof(h), MPI_BYTE, 0, MPI_COMM_WORLD);
  if (rank == 1) {
    void* peer; CK(cudaIpcOpenMemHandle(&peer, h, cudaIpcMemLazyEnablePeerAccess));
    CK(cudaMemcpy(buf, peer, n * sizeof(float), cudaMemcpyDeviceToDevice));
    std::vector<float> host(n);
    CK(cudaMemcpy(host.data(), buf, n * sizeof(float), cudaMemcpyDeviceToHost));
    size_t bad = 0; for (float v : host) bad += v != 42.0f;
    std::printf("ipc_probe: %s (%zu bad)\n", bad ? "FAIL" : "PASS", bad);
    CK(cudaIpcCloseMemHandle(peer));
  }
  MPI_Barrier(MPI_COMM_WORLD);
  CK(cudaFree(buf));
  MPI_Finalize();
}
```

```cpp
// src/memops.h
#pragma once
#include <cstddef>
#include "hxccl.h"
#include "transport.h"

class MemOps {
 public:
  virtual ~MemOps() = default;
  virtual hxcclResult_t copy(void* dst, const void* src, size_t bytes) = 0;
  // inout[i] = inout[i] op in[i]
  virtual hxcclResult_t reduce(void* inout, const void* in, size_t count, hxcclDataType_t dt,
                               hxcclRedOp_t op) = 0;
  // dst[i] = src[i] * scalar; scalar is host memory holding one dt element
  virtual hxcclResult_t scale(void* dst, const void* src, size_t count, hxcclDataType_t dt,
                              const void* scalar) = 0;
  virtual hxcclResult_t divide_trunc(void* buf, size_t count, hxcclDataType_t dt,
                                     int divisor) = 0;
  virtual hxcclResult_t alloc(size_t bytes, void** p) = 0;
  virtual void release(void* p) = 0;
  virtual Transport& tr() = 0;
  std::string error;  // set when a non-transport step fails
};

// Scratch buffer in the same memory space as the user buffers, released on scope exit.
class Scratch {
 public:
  Scratch(MemOps& m, size_t bytes) : m_(m) { if (bytes) rc = m_.alloc(bytes, &p_); }
  ~Scratch() { if (p_) m_.release(p_); }
  Scratch(const Scratch&) = delete;
  Scratch& operator=(const Scratch&) = delete;
  char* get() const { return static_cast<char*>(p_); }
  hxcclResult_t rc = hxcclSuccess;
 private:
  MemOps& m_;
  void* p_ = nullptr;
};

class HostOps : public MemOps {
 public:
  explicit HostOps(Transport& t) : t_(t) {}
  hxcclResult_t copy(void* dst, const void* src, size_t bytes) override;
  hxcclResult_t reduce(void* inout, const void* in, size_t count, hxcclDataType_t dt,
                       hxcclRedOp_t op) override;
  hxcclResult_t scale(void* dst, const void* src, size_t count, hxcclDataType_t dt,
                      const void* scalar) override;
  hxcclResult_t divide_trunc(void* buf, size_t count, hxcclDataType_t dt, int divisor) override;
  hxcclResult_t alloc(size_t bytes, void** p) override;
  void release(void* p) override;
  Transport& tr() override { return t_; }
 private:
  Transport& t_;
};
```

- [ ] **Step 3: 알고리즘을 `MemOps&`로 바꾸기**

규칙(모든 `algo_*.cc`에 같은 방식으로 적용):
- 시그니처의 `Transport& tr` → `MemOps& m`, 본문의 `tr.` → `m.tr().`
- `std::memcpy(a, b, n)` → `if ((r = m.copy(a, b, n)) != hxcclSuccess) return r;`(`hxcclResult_t r;`를 함수 앞에 선언)
- `std::vector<char> tmp(N);` → `Scratch tmp(m, N); if (tmp.rc) return tmp.rc;`, `tmp.data()` → `tmp.get()`
- `reduce_into(d, s, c, dt, op);` → `if ((r = m.reduce(d, s, c, dt, op)) != hxcclSuccess) return r;`
- `ring_reducescatter`의 `std::vector<char> work(send, send + n*block)` → `Scratch work(m, n * block); if (work.rc) return work.rc; if ((r = m.copy(work.get(), send, n * block))) return r;`

예시(`ring_allreduce` 바뀐 뒤):
```cpp
hxcclResult_t ring_allreduce(MemOps& m, int rank, int n, const void* send, void* recv,
                             size_t count, hxcclDataType_t dt, hxcclRedOp_t op) {
  const size_t es = dtype_size(dt);
  char* buf = static_cast<char*>(recv);
  hxcclResult_t r;
  if (send != recv && (r = m.copy(buf, send, count * es)) != hxcclSuccess) return r;
  if (n == 1 || count == 0) return hxcclSuccess;
  const int right = mod(rank + 1, n), left = mod(rank - 1, n);
  Scratch tmp(m, chunk_of(count, n, 0).len * es);
  if (tmp.rc) return tmp.rc;
  for (int s = 0; s < n - 1; ++s) {
    Chunk out = chunk_of(count, n, mod(rank - s, n));
    Chunk in = chunk_of(count, n, mod(rank - s - 1, n));
    if ((r = m.tr().sendrecv(right, buf + out.off * es, out.len * es, left, tmp.get(),
                             in.len * es)) != hxcclSuccess) return r;
    if ((r = m.reduce(buf + in.off * es, tmp.get(), in.len, dt, op)) != hxcclSuccess) return r;
  }
  for (int s = 0; s < n - 1; ++s) {
    Chunk out = chunk_of(count, n, mod(rank + 1 - s, n));
    Chunk in = chunk_of(count, n, mod(rank - s, n));
    if ((r = m.tr().sendrecv(right, buf + out.off * es, out.len * es, left, buf + in.off * es,
                             in.len * es)) != hxcclSuccess) return r;
  }
  return hxcclSuccess;
}
```

```cpp
const void* premul_input(MemOps& m, const OpPlan& p, const void* send, size_t count,
                         hxcclDataType_t dt, Scratch& tmp, hxcclResult_t* rc) {
  *rc = hxcclSuccess;
  if (!p.premul || count == 0) return send;
  if ((*rc = tmp.rc) != hxcclSuccess) return nullptr;
  *rc = m.scale(tmp.get(), send, count, dt, p.scalar);
  return tmp.get();
}
hxcclResult_t finish_op(MemOps& m, const OpPlan& p, void* buf, size_t count,
                        hxcclDataType_t dt) {
  return p.postdiv && count ? m.divide_trunc(buf, count, dt, p.divisor) : hxcclSuccess;
}
```

```cpp
#pragma once
#include <cstdint>
#include <type_traits>
#include "fp.h"
#include "gpu.h"
#include "hxccl.h"

// one element of dst op src; integer sum/prod wrap like the GPU (unsigned math)
template <typename T>
HX_HD inline T elem_apply(T a, T b, hxcclRedOp_t op) {
  using U = typename std::conditional_t<std::is_integral_v<T>, std::make_unsigned<T>,
                                        std::common_type<T>>::type;
  switch (op) {
    case hxcclSum: return static_cast<T>(static_cast<U>(a) + static_cast<U>(b));
    case hxcclProd: return static_cast<T>(static_cast<U>(a) * static_cast<U>(b));
    case hxcclMax: return a < b ? b : a;    // std::max(a, b)
    case hxcclMin: return b < a ? b : a;    // std::min(a, b)
    default: return a;
  }
}
template <typename S, float (*ToF)(S), S (*FromF)(float)>
HX_HD inline S elem_apply_small(S d, S s, hxcclRedOp_t op) {
  const float a = ToF(d), b = ToF(s);
  const float r = op == hxcclSum ? a + b : op == hxcclProd ? a * b
                  : op == hxcclMax ? fmaxf(a, b) : fminf(a, b);
  return FromF(r);
}
template <typename T, typename W>
HX_HD inline T elem_div(T v, int d) { return static_cast<T>(static_cast<W>(v) / static_cast<W>(d)); }
```

```cpp
#include <cstring>
#include "elem.h"
#include "gpu_reduce.h"
#include "reduce.h"

namespace {
constexpr int kThreads = 256;
inline int blocks(size_t n) {
  size_t b = (n + kThreads - 1) / kThreads;
  return static_cast<int>(b < 65535 ? (b ? b : 1) : 65535);
}
template <typename T>
__global__ void k_reduce(T* d, const T* s, size_t n, hxcclRedOp_t op) {
  for (size_t i = blockIdx.x * size_t(blockDim.x) + threadIdx.x; i < n; i += size_t(gridDim.x) * blockDim.x)
    d[i] = elem_apply<T>(d[i], s[i], op);
}
template <typename S, float (*ToF)(S), S (*FromF)(float)>
__global__ void k_reduce_small(S* d, const S* s, size_t n, hxcclRedOp_t op) {
  for (size_t i = blockIdx.x * size_t(blockDim.x) + threadIdx.x; i < n; i += size_t(gridDim.x) * blockDim.x)
    d[i] = elem_apply_small<S, ToF, FromF>(d[i], s[i], op);
}
template <typename T>
__global__ void k_scale(T* d, const T* s, size_t n, T k) {
  for (size_t i = blockIdx.x * size_t(blockDim.x) + threadIdx.x; i < n; i += size_t(gridDim.x) * blockDim.x)
    d[i] = elem_apply<T>(s[i], k, hxcclProd);
}
template <typename S, float (*ToF)(S), S (*FromF)(float)>
__global__ void k_scale_small(S* d, const S* s, size_t n, S k) {
  for (size_t i = blockIdx.x * size_t(blockDim.x) + threadIdx.x; i < n; i += size_t(gridDim.x) * blockDim.x)
    d[i] = elem_apply_small<S, ToF, FromF>(s[i], k, hxcclProd);
}
template <typename T, typename W>
__global__ void k_div(T* d, size_t n, int div) {
  for (size_t i = blockIdx.x * size_t(blockDim.x) + threadIdx.x; i < n; i += size_t(gridDim.x) * blockDim.x)
    d[i] = elem_div<T, W>(d[i], div);
}
}  // namespace

cudaError_t gpu_reduce(void* inout, const void* in, size_t n, hxcclDataType_t dt,
                       hxcclRedOp_t op, cudaStream_t st) {
  if (!n) return cudaSuccess;
#define HX_K(DT, T) case DT: k_reduce<T><<<blocks(n), kThreads, 0, st>>>(static_cast<T*>(inout), static_cast<const T*>(in), n, op); break;
#define HX_S(DT, S, TO, FROM) case DT: k_reduce_small<S, TO, FROM><<<blocks(n), kThreads, 0, st>>>(static_cast<S*>(inout), static_cast<const S*>(in), n, op); break;
  switch (dt) {
    HX_K(hxcclInt8, int8_t) HX_K(hxcclUint8, uint8_t) HX_K(hxcclInt32, int32_t)
    HX_K(hxcclUint32, uint32_t) HX_K(hxcclInt64, int64_t) HX_K(hxcclUint64, uint64_t)
    HX_K(hxcclFloat32, float) HX_K(hxcclFloat64, double)
    HX_S(hxcclFloat16, uint16_t, fp::half_to_float, fp::float_to_half)
    HX_S(hxcclBfloat16, uint16_t, fp::bf16_to_float, fp::float_to_bf16)
    HX_S(hxcclFloat8e4m3, uint8_t, fp::e4m3_to_float, fp::float_to_e4m3)
    HX_S(hxcclFloat8e5m2, uint8_t, fp::e5m2_to_float, fp::float_to_e5m2)
    default: return cudaErrorInvalidValue;
  }
#undef HX_K
#undef HX_S
  return cudaGetLastError();
}
```
`gpu_scale`은 같은 switch로 `host_scalar`를 그 타입 값으로 `memcpy`해 `k_scale`/`k_scale_small`에 넘긴다(정수 dtype은 `cudaErrorInvalidValue`). `gpu_divide_trunc`은 `reduce.cc`의 `HX_DIV`와 같은 (T, W) 짝으로 `k_div`를 부른다(실수 dtype은 `cudaErrorInvalidValue`).

```cpp
#include <cstdlib>
#include "memspace.h"

namespace {
// 1 = device, 0 = host, -1 = ignore (null)
int space(const void* p) {
  if (!p) return -1;
  cudaPointerAttributes a{};
  if (cudaPointerGetAttributes(&a, p) != cudaSuccess) { cudaGetLastError(); return 0; }
  return a.type == cudaMemoryTypeDevice || a.type == cudaMemoryTypeManaged ? 1 : 0;
}
size_t chunk_bytes() {
  const char* e = std::getenv("HXCCL_IPC_CHUNK");
  size_t v = e ? std::strtoull(e, nullptr, 10) : 0;
  return v >= 64 ? v : size_t(4) << 20;
}
}  // namespace

MemOps* ops_for(hxcclComm* c, hxcclStream_t stream, const void* a, const void* b,
                hxcclResult_t* rc) {
  *rc = hxcclSuccess;
  const int sa = space(a), sb = space(b);
  if (sa >= 0 && sb >= 0 && sa != sb) {
    *rc = comm_fail(c, hxcclInvalidArgument,
                    "send and recv buffers must both be host or both be device memory");
    return nullptr;
  }
  if (sa != 1 && sb != 1) return c->host_ops.get();
  if (!c->dev_ops) {
    auto d = std::make_unique<DeviceOps>(c->mpi, c->rank, c->nranks, chunk_bytes());
    if ((*rc = d->init()) != hxcclSuccess) {
      comm_fail(c, *rc, d->error);
      return nullptr;
    }
    c->dev_ops = std::move(d);
  }
  auto* d = static_cast<DeviceOps*>(c->dev_ops.get());
  d->set_stream(static_cast<cudaStream_t>(stream));
  return d;
}
```

```cpp
#include <cuda_runtime.h>
#include <nvtx3/nvToolsExt.h>
#include <algorithm>
#include <deque>
#include "gpu.h"
#include "transport.h"

// One staging buffer per (receiver, sender) pair, owned by the receiver and opened by the
// sender over CUDA IPC. Per chunk: receiver sends READY, sender copies into the staging buffer,
// synchronizes its stream and sends DONE, receiver copies out. Control messages use their own
// tags so they never match user data on the MPI transport of the same communicator.
namespace {
constexpr int kReadyBase = 1000, kDoneBase = 2000;
}

struct IpcTransport::Op {
  bool is_send;
  int peer;
  char* buf;
  size_t bytes;
  int tag;
  size_t off = 0;
  int state = 0;  // 0 = start chunk, 1 = waiting for READY or DONE
  MPI_Request req = MPI_REQUEST_NULL, ctrl_req = MPI_REQUEST_NULL;
  char ctrl = 0, ctrl_in = 0;
};
```

핵심 함수:
```cpp
IpcTransport::IpcTransport(MPI_Comm comm, int rank, int n, size_t chunk)
    : comm_(comm), rank_(rank), n_(n), chunk_(chunk), mine_(n, nullptr), peer_(n, nullptr),
      sends_(n), recvs_(n) {}

hxcclResult_t IpcTransport::init() {
  std::vector<cudaIpcMemHandle_t> mine_h(n_), all(size_t(n_) * n_);
  for (int s = 0; s < n_; ++s) {
    if (s == rank_) continue;
    if (hxcclResult_t r = cuda(cudaMalloc(&mine_[s], chunk_), "cudaMalloc staging")) return r;
    if (hxcclResult_t r = cuda(cudaIpcGetMemHandle(&mine_h[s], mine_[s]), "cudaIpcGetMemHandle"))
      return r;
  }
  const int hb = static_cast<int>(sizeof(cudaIpcMemHandle_t)) * n_;
  if (hxcclResult_t r = mpi(MPI_Allgather(mine_h.data(), hb, MPI_BYTE, all.data(), hb, MPI_BYTE,
                                          comm_), "MPI_Allgather ipc handles")) return r;
  for (int p = 0; p < n_; ++p) {
    if (p == rank_) continue;
    // all[p * n + rank_] is the buffer rank p keeps for data from me
    if (hxcclResult_t r = cuda(cudaIpcOpenMemHandle(&peer_[p], all[size_t(p) * n_ + rank_],
                                                    cudaIpcMemLazyEnablePeerAccess),
                               "cudaIpcOpenMemHandle")) return r;
  }
  return hxcclSuccess;
}

IpcTransport::~IpcTransport() {
  for (void* p : peer_) if (p) cudaIpcCloseMemHandle(p);
  for (void* p : mine_) if (p) cudaFree(p);
}

hxcclResult_t IpcTransport::isend(int to, const void* buf, size_t bytes, int tag) {
  if (bytes == 0) return hxcclSuccess;  // both sides know the size; nothing to move
  sends_[to].push_back(Op{true, to, const_cast<char*>(static_cast<const char*>(buf)), bytes, tag});
  return hxcclSuccess;
}
hxcclResult_t IpcTransport::irecv(int from, void* buf, size_t bytes, int tag) {
  if (bytes == 0) return hxcclSuccess;
  recvs_[from].push_back(Op{false, from, static_cast<char*>(buf), bytes, tag});
  return hxcclSuccess;
}

hxcclResult_t IpcTransport::progress(Op& o, bool* finished) {
  *finished = false;
  const size_t len = std::min(chunk_, o.bytes - o.off);
  int flag = 0;
  if (o.is_send) {
    if (o.state == 0) {  // wait for READY
      if (hxcclResult_t r = mpi(MPI_Irecv(&o.ctrl_in, 1, MPI_BYTE, o.peer, kReadyBase + o.tag, comm_, &o.req), "MPI_Irecv ready")) return r;
      o.state = 1;
    }
    if (hxcclResult_t r = mpi(MPI_Test(&o.req, &flag, MPI_STATUS_IGNORE), "MPI_Test ready")) return r;
    if (!flag) return hxcclSuccess;
    nvtxRangePushA("ipc:copy");
    hxcclResult_t r = cuda(cudaMemcpyAsync(peer_[o.peer], o.buf + o.off, len, cudaMemcpyDeviceToDevice, stream_), "cudaMemcpyAsync to peer");
    if (!r) r = cuda(cudaStreamSynchronize(stream_), "cudaStreamSynchronize");
    nvtxRangePop();
    if (r) return r;
    if ((r = mpi(MPI_Send(&o.ctrl, 1, MPI_BYTE, o.peer, kDoneBase + o.tag, comm_), "MPI_Send done"))) return r;
  } else {
    if (o.state == 0) {  // announce the free buffer, then wait for DONE
      if (hxcclResult_t r = mpi(MPI_Send(&o.ctrl, 1, MPI_BYTE, o.peer, kReadyBase + o.tag, comm_), "MPI_Send ready")) return r;
      if (hxcclResult_t r = mpi(MPI_Irecv(&o.ctrl_in, 1, MPI_BYTE, o.peer, kDoneBase + o.tag, comm_, &o.req), "MPI_Irecv done")) return r;
      o.state = 1;
    }
    if (hxcclResult_t r = mpi(MPI_Test(&o.req, &flag, MPI_STATUS_IGNORE), "MPI_Test done")) return r;
    if (!flag) return hxcclSuccess;
    hxcclResult_t r = cuda(cudaMemcpyAsync(o.buf + o.off, mine_[o.peer], len, cudaMemcpyDeviceToDevice, stream_), "cudaMemcpyAsync from staging");
    if (!r) r = cuda(cudaStreamSynchronize(stream_), "cudaStreamSynchronize");
    if (r) return r;
  }
  o.off += len;
  o.state = 0;
  if (o.off == o.bytes) {
    *finished = true;
    if (o.is_send) { bytes_sent += o.bytes; ++msgs_sent; }
  }
  return hxcclSuccess;
}

hxcclResult_t IpcTransport::waitall() {
  for (;;) {
    bool any = false;
    for (int p = 0; p < n_; ++p)
      for (auto* q : {&sends_[p], &recvs_[p]}) {
        if (q->empty()) continue;
        any = true;
        bool done = false;
        if (hxcclResult_t r = progress(q->front(), &done)) { cancel_all(); return r; }
        if (done) q->pop_front();
      }
    if (!any) return hxcclSuccess;
  }
}

hxcclResult_t IpcTransport::sendrecv(int to, const void* sb, size_t sn, int from, void* rb, size_t rn) {
  if (hxcclResult_t r = irecv(from, rb, rn, kCollTag)) return r;
  if (hxcclResult_t r = isend(to, sb, sn, kCollTag)) return r;
  return waitall();
}
hxcclResult_t IpcTransport::send(int to, const void* b, size_t n) {
  if (hxcclResult_t r = isend(to, b, n, kCollTag)) return r;
  return waitall();
}
hxcclResult_t IpcTransport::recv(int from, void* b, size_t n) {
  if (hxcclResult_t r = irecv(from, b, n, kCollTag)) return r;
  return waitall();
}
void IpcTransport::cancel_all() {
  for (auto* qs : {&sends_, &recvs_})
    for (auto& q : *qs) {
      for (Op& o : q) if (o.req != MPI_REQUEST_NULL) { MPI_Cancel(&o.req); MPI_Request_free(&o.req); }
      q.clear();
    }
}
hxcclResult_t IpcTransport::cuda(cudaError_t e, const char* what) {
  if (e == cudaSuccess) return hxcclSuccess;
  error = std::string(what) + ": " + cudaGetErrorString(e);
  return hxcclUnhandledCudaError;
}
hxcclResult_t IpcTransport::mpi(int rc, const char* what) {
  if (rc == MPI_SUCCESS) return hxcclSuccess;
  char msg[MPI_MAX_ERROR_STRING]; int len = 0;
  MPI_Error_string(rc, msg, &len);
  error = std::string(what) + ": " + std::string(msg, len);
  return hxcclSystemError;
}
```

```cpp
void ring_shift(hxcclComm_t c, size_t count) {
```

```cpp
#include <mpi.h>
#include <torch/csrc/distributed/c10d/Backend.hpp>
#include <torch/csrc/distributed/c10d/Store.hpp>

namespace {
using namespace c10d;

hxcclDataType_t to_dt(at::ScalarType t) {
  switch (t) {
    case at::kChar: return hxcclInt8;   case at::kByte: return hxcclUint8;
    case at::kInt: return hxcclInt32;   case at::kLong: return hxcclInt64;
    case at::kHalf: return hxcclFloat16; case at::kFloat: return hxcclFloat32;
    case at::kDouble: return hxcclFloat64; case at::kBFloat16: return hxcclBfloat16;
    case at::kFloat8_e4m3fn: return hxcclFloat8e4m3; case at::kFloat8_e5m2: return hxcclFloat8e5m2;
    default: TORCH_CHECK_TYPE(false, "hxccl: unsupported dtype ", t);
  }
}
hxcclRedOp_t to_op(const ReduceOp& op) {
  switch (op.op_) {
    case ReduceOp::SUM: return hxcclSum;   case ReduceOp::PRODUCT: return hxcclProd;
    case ReduceOp::MIN: return hxcclMin;   case ReduceOp::MAX: return hxcclMax;
    case ReduceOp::AVG: return hxcclAvg;
    default: TORCH_CHECK_VALUE(false, "hxccl: unsupported reduce op");
  }
}
void check_tensor(const at::Tensor& t) {
  TORCH_CHECK_VALUE(t.is_contiguous(), "hxccl: tensors must be contiguous");
  TORCH_CHECK_VALUE(t.is_cuda(), "hxccl: tensors must be on a CUDA device");
}
void ok(hxcclResult_t r, hxcclComm_t c, const char* what) {
  TORCH_CHECK(r == hxcclSuccess, "hxccl ", what, " failed (", int(r), "): ",
              hxcclGetLastError(c));
}
cudaStream_t cur() { return at::cuda::getCurrentCUDAStream().stream(); }

class DoneWork : public Work {
 public:
  DoneWork(OpType t, std::vector<at::Tensor> out) : Work(-1, t) {
    fut_ = c10::make_intrusive<c10::ivalue::Future>(c10::ListType::create(c10::TensorType::get()));
    fut_->markCompleted(c10::IValue(out));
  }
  bool isCompleted() override { return true; }
  bool isSuccess() const override { return true; }
  bool wait(std::chrono::milliseconds) override { return true; }
  c10::intrusive_ptr<c10::ivalue::Future> getFuture() override { return fut_; }
 private:
  c10::intrusive_ptr<c10::ivalue::Future> fut_;
};

class HxcclBackend : public Backend {
 public:
  HxcclBackend(const c10::intrusive_ptr<Store>& store, int rank, int size) : Backend(rank, size) {
    hxcclUniqueId id;
    if (rank == 0) {
      ok(hxcclGetUniqueId(&id), nullptr, "GetUniqueId");
      store->set("hxccl_uid", std::vector<uint8_t>((uint8_t*)&id, (uint8_t*)&id + sizeof(id)));
    }
    auto v = store->get("hxccl_uid");
    std::memcpy(&id, v.data(), sizeof(id));
    ok(hxcclCommInitRank(&comm_, size, id, rank), nullptr, "CommInitRank");
  }
  ~HxcclBackend() override { if (comm_) hxcclCommDestroy(comm_); }
  const std::string getBackendName() const override { return "hxccl"; }

  c10::intrusive_ptr<Work> allreduce(std::vector<at::Tensor>& ts, const AllreduceOptions& o) override {
    for (auto& t : ts) {
      check_tensor(t);
      ok(hxcclAllReduce(t.data_ptr(), t.data_ptr(), t.numel(), to_dt(t.scalar_type()), to_op(o.reduceOp), comm_, cur()), comm_, "AllReduce");
    }
    return c10::make_intrusive<DoneWork>(OpType::ALLREDUCE, ts);
  }
  c10::intrusive_ptr<Work> _allgather_base(at::Tensor& out, at::Tensor& in, const AllgatherOptions&) override {
    check_tensor(in); check_tensor(out);
    ok(hxcclAllGather(in.data_ptr(), out.data_ptr(), in.numel(), to_dt(in.scalar_type()), comm_, cur()), comm_, "AllGather");
    return c10::make_intrusive<DoneWork>(OpType::_ALLGATHER_BASE, std::vector<at::Tensor>{out});
  }
  c10::intrusive_ptr<Work> _reduce_scatter_base(at::Tensor& out, at::Tensor& in, const ReduceScatterOptions& o) override {
    check_tensor(in); check_tensor(out);
    ok(hxcclReduceScatter(in.data_ptr(), out.data_ptr(), out.numel(), to_dt(in.scalar_type()), to_op(o.reduceOp), comm_, cur()), comm_, "ReduceScatter");
    return c10::make_intrusive<DoneWork>(OpType::_REDUCE_SCATTER_BASE, std::vector<at::Tensor>{out});
  }
  c10::intrusive_ptr<Work> broadcast(std::vector<at::Tensor>& ts, const BroadcastOptions& o) override {
    for (auto& t : ts) {
      check_tensor(t);
      ok(hxcclBroadcast(t.data_ptr(), t.data_ptr(), t.numel(), to_dt(t.scalar_type()), int(o.rootRank), comm_, cur()), comm_, "Broadcast");
    }
    return c10::make_intrusive<DoneWork>(OpType::BROADCAST, ts);
  }
  c10::intrusive_ptr<Work> send(std::vector<at::Tensor>& ts, int dst, int) override {
    check_tensor(ts[0]);
    ok(hxcclSend(ts[0].data_ptr(), ts[0].numel(), to_dt(ts[0].scalar_type()), dst, comm_, cur()), comm_, "Send");
    return c10::make_intrusive<DoneWork>(OpType::SEND, ts);
  }
  c10::intrusive_ptr<Work> recv(std::vector<at::Tensor>& ts, int src, int) override {
    check_tensor(ts[0]);
    ok(hxcclRecv(ts[0].data_ptr(), ts[0].numel(), to_dt(ts[0].scalar_type()), src, comm_, cur()), comm_, "Recv");
    return c10::make_intrusive<DoneWork>(OpType::RECV, ts);
  }
  c10::intrusive_ptr<Work> barrier(const BarrierOptions&) override {
    auto t = at::zeros({1}, at::TensorOptions().device(at::kCUDA).dtype(at::kInt));
    std::vector<at::Tensor> v{t};
    return allreduce(v, AllreduceOptions());
  }
 private:
  hxcclComm_t comm_ = nullptr;
};
```

```python
# mpirun -np N python python/bench_allreduce.py --backend hxccl|gloo [--out file.csv]
import argparse, csv, statistics, time
import torch, torch.distributed as dist
import hxccl_torch  # noqa: F401

p = argparse.ArgumentParser()
p.add_argument("--backend", default="hxccl")
p.add_argument("--out")
a = p.parse_args()
dist.init_process_group(a.backend)
dev = "cuda" if a.backend != "gloo" else "cpu"
rows = []
for size in [1 << k for k in range(12, 29, 2)]:  # 4 KiB .. 256 MiB
    t = torch.ones(size // 4, device=dev)
    for _ in range(5):
        dist.all_reduce(t)
    times = []
    for _ in range(20):
        dist.barrier()
        if dev == "cuda":
            torch.cuda.synchronize()
        t0 = time.perf_counter()
        dist.all_reduce(t)
        if dev == "cuda":
            torch.cuda.synchronize()
        times.append(time.perf_counter() - t0)
    med = statistics.median(times)
    rows.append((a.backend, dist.get_world_size(), size, med * 1e6, size / med / 1e9))
if dist.get_rank() == 0:
    for r in rows:
        print("%s np=%d bytes=%d median_us=%.1f GBps=%.2f" % r)
    if a.out:
        with open(a.out, "a", newline="") as f:
            csv.writer(f).writerows(rows)
dist.destroy_process_group()
```
